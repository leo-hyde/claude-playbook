# Methods: written ways of doing recurring work

Each is one page: when to use it, inputs, steps (with "stop and ask the
user" points), output, done check, and what to record. Every project's
AGENTS.md lists them.

| Method | Use it for |
|---|---|
| [build-a-feature.md](build-a-feature.md) | Any new feature or change: list the whole objective, spec, pull request, check, merge |
| [research-to-doc.md](research-to-doc.md) | Turning a question into one document people decide or build from |
| [pick-up-where-we-left-off.md](pick-up-where-we-left-off.md) | Session start, "where are we?", "carry on" |

Add a method after doing the same job twice. A project's own methods are
short sections in its AGENTS.md, moving to its own `methods/` folder once
there are more than three. A method used often becomes a skill (a `/name`
command). General ones live here, in general terms (this repo is public).
