# Decisions

One entry per decision, newest first, so later sessions don't undo a choice
without knowing why it was made. Add one whenever the user (or Claude, with the user's
agreement) picks one way over another. If a decision is reversed, add a new
entry and mark the old one "Replaced by <date>"; don't delete it.
